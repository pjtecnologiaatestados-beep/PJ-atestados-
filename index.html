Como obter suas credenciais:
1. Acesse console.firebase.google.com
2. Crie um projeto → Adicionar app Web → Copie o firebaseConfig
3. Menu Authentication → Método de login → ative Anônimo
4. Menu Firestore Database → Criar banco de dados
5. Cole os valores abaixo (ou importe o arquivo de credenciais) e clique em Conectar
